# F-105 — TailJumpFreshJvmTest leaves PIT's test set

- **Assumption**: ADR-0046 #113 "PIT" and F-84 (a) say a test class leaves PIT's test set only under
  a finding, with measured seconds and its first-kill count.
- **How it fails**: #118 excluded `TailJumpFreshJvmTest` (jq-core and oracle POMs,
  `scripts/test/pit-exclusions-test.sh`) and justified it only in a POM comment.
- **Measured** (#118 implementer, impl/118 1a9b028, `.logs/118-pit-tailjump.log` in its worktree):
  - surefire time 1.84 s, 1.57 s and 1.59 s over three runs;
  - as jq-core's only PIT test, it is the killer of 0 of 3 751 mutants and covers 0 of 5 413 lines
    in the minion. Its work runs in child JVMs, which PIT does not see.
- **Severity**: minor. The exclusion loses no kill.
- **Change made**: the exclusion stays. The POM comments carry these numbers.
