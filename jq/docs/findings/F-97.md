# F-97 — the full calibration matrix takes hours, not the 45-minute target

- **Assumption**: ADR-0046 #113's rulings (2026-11-15). The full matrix runs at the spec gate and
  nightly, and its measured time has a 45-minute target; above that is a finding. The adviser's rough
  estimate was 30–45 min.
- **How it fails**: the first matrix run (t/113-calibration at 2ff5ff2, started 07:17Z) was about 38 %
  through its 4-wide `-Xint` and C1 phase after 27 min. 234 warm children, run one at a time, follow.
  The test author estimates 3–5 h in total.
  - The cost comes from cold `-Xint` edges: a bisection with one fresh child per probe (675 cold
    probes in 27 min), 13 shapes, 2 modes, 3 threads.
  - The run shares a 4 vCPU container with other agents' builds. Edges are depths, not times, but
    warm children were seen to move under load (warm W gave 2971 four times and 2075 once).
- **Severity**: major. A spec gate that takes hours cannot run per spec as ADR-0014 plans, and warm
  cells measured under load may be lower than on a quiet machine.
- **Evidence**: the #113 test author's hand-back; `.logs/113-matrix.log` and
  `jq-core/target/calibration-progress.log` in the t/113 worktree. The final time-ms row is NOT_RUN
  until the run ends.
- **Change made**: none yet. The run continues. Options for a later ruling, none chosen:
  - seed cold bisections from the linked edge, or from the record, with a narrow window;
  - run the full matrix nightly only, and at the spec gate only the cells whose record rows changed;
  - let warm children run in parallel only on a machine with spare cores.
  No cell is cut without a ruling (ADR-0046 #113).
- **Amended (#199 rulings, 2026-11-15)**: after #113 the spec-gate calibration step takes about 54 min
  (pool 2 636 s, `edgeIsExact` 575 s unseeded, heap 25 s), and with #199's 308 cells about 64–72 min.
  Seeding `edgeIsExact` (#199) brings it to about 57–65 min. Below 45 min needs the warm phase (30–34
  min) cut. The grilling-adviser keeps "one at a time" for validity. Whether to relax it (2-wide), to
  drop the target, or to narrow the gate's scope is the owner's question; #199 measures warm alone
  against 2-wide (C5).
