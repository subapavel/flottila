# F-86 — Spec 2a's jq-core keeps mutants that no test can kill

- **Assumption**:
  - ADR-0014 step 2 and `ratchet/mutation.tsv`: jq-core holds 98 %, so at most 68 of its 3 439
    mutants may survive.
  - #193: every listed survivor (`.logs/spec56-survivors-jq-core.tsv`, 97 rows) gets a killing
    test, or a reason why none exists.
- **How it fails**:
  - #193 killed 35 of the 97, each hand-applied and seen red (`.logs/193-kills.tsv`). PIT run 2
    on b7b4df9 leaves 62 alive in jq-core's own run (`.logs/193-pit2.log`,
    `.logs/193-pit2-alive-jq-core.tsv`).
  - The test-author claims these as equivalent. The reason for each is in `193-kills.tsv`:
    - `Slice` 223, 226, 237, 242 and 248: each boundary assigns the value it compares with.
    - `CanonicalForm` 76, 78, 80 (three), 83, 84, 168, 187 and 296.
    - `DoubleNumber` 78, 95, 117 and 119.
    - `LiteralNumber` 102, 107, 145, 186 and 209.
    - `KeyProof` 95, 131, 211, 247, 261 and 409.
  - Equivalent in outcome:
    - `Binder` 891 changes only which Stub message a missed cycle gives.
    - `KeyProof` 469 can read past its array only with about 2^19 colliding keys.
  - 26 survivors have no reasoning yet, and none is claimed equivalent: `Printer` 8, `Parser` 3,
    `JsonStrings` 3, `Resolver` 604, 605 and 963, `Binder` 250 and 275, `Sort` 2, `Built` 2,
    `Resolver$Links` 810 and `BuiltObject` 64. `KeyProof` 512 and 514–516 are also not killed.
  - `Resolver.built` 331 (MathMutator) was MEMORY_ERROR in the reference run, which counts as
    killed, and SURVIVED in both #193 runs. It is not on the list. If oracle does not kill it, the
    union has 63 survivors.
- **Severity**: minor (the ratchet holds; the margin is 5 or 6 mutants).
- **Evidence**:
  - #193: `.logs/193-kills.tsv`, `.logs/193-pit2.log`, `.logs/193-pit2-alive-*.tsv`.
  - The reference run in `.logs/spec56-pit-ref/`.
  - Both reviews of #193.
- **Change made**:
  - No ADR changes. The ratchet is not lowered and no mutator is excluded.
  - The claimed equivalents stay counted as survivors. Removing them takes a production change
    (as F-85 did for query-core), or an owner's yes to a PIT exclusion.
  - The 26 unreasoned survivors go to a later round, and the spec gate's rerun decides the margin.
  - Two `KeyProofEdgesTest` cases pin tick counts that hold only for the present key hash, which
    ADR-0044 does not fix. Changing the hash must update them, and the change says so.
