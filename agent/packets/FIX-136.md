## Decision
- P1 `FLOTTILA_PG_DURABILITY` = `local` | `ha`, component `Durability` of NodeConfig.Pg (6-arg ctor → LOCAL); unset →
  `local` when not deployed (dev, ci), `ha` when deployed; other values refused naming the key and both values.
  Rejected: the loopback default (a proxy at 127.0.0.1 would default a production node to local).
- P2 Node.connectOptions adds startup parameters `synchronous_commit=on` and `statement_timeout=0` (both profiles), so
  pool, membership and LISTEN carry them on every (re)connect. Flyway unpinned (the next sync commit covers it).
- P3/P4 `PgDurability.check(pool, profile)` replaces requireSynchronousCommit before migrating, one read; pure
  `PgDurability.verdict(Durability, Server)`. Refused in both: session value ≠ on (a pooler dropped the parameter); server
  in recovery (host names a standby). Refused in ha: empty synchronous_standby_names; no pg_read_all_stats (message names
  `GRANT pg_monitor TO <user>`); 0 sync/quorum standbys streaming.
- P5 notices (`notices()`, /health): local always states the promise ("survives a Postgres crash, not a promotion or the
  loss of its host"); local with streaming standbys names them and `ha`; ha with non-sync standbys names D-115.
- P6 runtime: no watch (D-115: settings checked at start only — the designer's P7 is dropped; CONSIDER row). A lost
  standby makes commits wait in Postgres; saveTimeout bounds the answer (503); the node never cancels a commit.
- Accepted residuals (documented): an operator's pg_cancel_backend on a waiting commit returns success for a local-only
  commit (syncrep.c); managed cloud PG with empty names is refused by ha → ISSUE-5.
- D-061 amended (its start refusal of database-level async commit is replaced by the pin). NodeIT
  aNodeRefusesAsynchronousCommit (:1742) rewritten by the test-author as
  aDatabaseLevelAsynchronousCommitDoesNotWeakenTheNodesSessions.
- Docs: ARCHITECTURE §3 :155 (synchronous standby + failover (ha) or single server (local)), §4 paragraph "Postgres
  durability profiles" after the durable save, changelog; D-127; F-29 F3.1 row at the commit. FIX-137 follows (designer P8).
