Row: `agent/BACKLOG.md` FIX-225, under MAIN-1. The race of FIX-213 and FIX-222: the journal counts the

starts, on a `journal-open-N` virtual thread (`Journal.java` :919, `createFile` :927), before the file
exists on disk. A test that compares the journal's count or rows with the disk without waiting for
that pre-open races with it. Never seen failing by chance; shown with a delay
(`agent/work/FIX-222-demo-old.log` :55914-55916).
