# P2-09a — concurrency limit per target, core (class C; D-099 draft, F-24)

Architect 2026-11-03 from the designer's draft (approved; P2-09 split into a core and b runtime). Defaults: maxCalls 16, maxWait 5s.
sftp answers target now (contract pins the format).

## Shape
- api `Component`: `default Optional<String> target(EndpointConfig cfg) { return Optional.empty(); }` — the system a producer of cfg
  calls, `scheme://authority` lower-cased, host:port with the scheme's default port filled, never userinfo/path/query; from cfg
  alone (no DNS, no I/O), like listensOn/polls/dedupeBy. @since per PublicTypesHaveSinceTest rules if it applies to methods.
- core `admission.TargetLimit` (final): `TargetLimit(String target, int maxCalls, Duration maxWait, Timer timer)` (positive, finite,
  else IAE); `Future<Permit> acquire()` never blocks, FIFO, fails after maxWait on the injected Timer with `new NackException("target
  <t> busy: <n> calls in flight, waited <w>", true)`; `<T> T call(Supplier<Future<T>> send) throws Exception` waits on the message's
  virtual thread, runs send there, holds the permit until send's future settles (not until the caller leaves); an interrupt while
  waiting withdraws the request (nothing sent, flag restored, IE rethrown) and a grant racing it is released; a grant only completes
  the waiter's promise (send never runs on the releasing thread); `Gauge gauge()` record(target, maxCalls, maxWait, inFlight,
  waiting, refused).
- core `admission.Targets(Limit defaults, Map<String, Limit> overrides, Timer timer)`, `record Limit(int maxCalls, Duration maxWait)`;
  `TargetLimit of(String target)` (one per key, lifetime of the Targets); `TargetLimit unshared()` (defaults, not listed);
  `List<Gauge> gauges()` (sorted by target).
- FlowBuilder: `targets(Targets)` like dlq/queue; without it a builder-private Targets with the defaults (16, 5s) on the Runtime's
  timer. In `to`, at build time: `limit = component.target(cfg).map(targets::of).orElseGet(targets::unshared)`; stage =
  `limit.call(() -> producer.send(forward.apply(e)))`, inside Retry and inside Recorder; Replay uses the same stage.
- http: target from `url` (else the URI), keeps https; sftp: from host/port options over the URI (D-086).
