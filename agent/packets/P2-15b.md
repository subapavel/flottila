## Design (accepted)
- SPI: api `@FunctionalInterface Deadline { Duration remaining(); }` — live, non-blocking, any thread, finite; ≤ 0 = passed; may
  grow (renewed fence), never past the message deadline. api `Producer`: `default Future<Envelope> send(Envelope e, Deadline d)` —
  remaining ≤ 0 → retryable NackException, nothing started; else `send(e)`. Overriders cut a send once a re-read finds ≤ 0.
  `send(e)` unchanged.
- core `node.Fence extends BooleanSupplier { long openNanos(); default getAsBoolean() = openNanos() > 0 }`; NodeLease implements it
  (`joined && !superseded ? fenceUntil − nanos() : 0`). The fence never becomes an Instant.
- Send (at-least-once, under the permit): openNanos ≤ 0 → FencedException; Deadline = min(between(clock.instant(), ctx.deadline()),
  ofNanos(fence.openNanos())), both re-read per call; remaining ≤ 0 → retryable Nack "deadline passed", producer not called; else
  `send(e, d)`. `FlowBuilder.fence(BooleanSupplier)` keeps its signature; a `Fence` argument also bounds sends (one instanceof).
- Abandon (only with a Fence): a runtime timer at openNanos re-reads: > 0 re-arm; ≤ 0 fails the run's wait with FencedException
  (not retried, not parked, item unsettled → doubts+1 on the next hand-out). A producer failure landing while the fence is closed
  → FencedException(cause). TargetLimit.call(within, send, awaited): the permit follows the raw future (held until it settles).
- http: `HttpComponent(Vertx, BlobStore, IdGenerator, Timer)` (3-arg keeps a Vert.x-backed Timer; runtime passes Runtime.timer()).
  d ≤ 0 → no request, not counted; else connect timeout = min(left, timeoutMs); a Timer at `left` re-reads: re-arm or reset the
  request (one not yet obtained is reset unsent); no reply stored; timer cancelled on settle. The cut is the same retryable Nack
  type as today's timeoutMs failure. Vert.x 5.1 APIs (RequestOptions timeout semantics, HttpClientRequest.reset, putHeader
  replace) by javap on the resolved jar before use.
- Wire: api `Envelope.H_MESSAGE_ID = "x-message-id"`; the http producer drops any forwarded x-message-id (case-insensitive) and
  sets e.id(). Mock: the envelope its consumer receives carries the header; `sent()` unchanged; d ≤ 0 not started/recorded; held
  answers cut on its Timer. Not renameable now (P2-15 decision 4).
- Split: `Split(Function<Envelope, List<Body>> parts)`, child id `parent.id() + "." + i` (i from 0); `ids` dropped (FlowBuilder:479).
- D-113 (draft): amends D-100 — producers see the deadline through `Deadline`; a send is cut at it; none starts after it. ARCHITECTURE
  sections carrying D-100 edited with a changelog entry. FIX-118's producer half done here; its step half stays open (row reworded).
