## Facts (designer)
Bench sets `synchronous_commit=on` by ALTER DATABASE (NodeBenchMain.java:124-125), refuses off (:165-166); run.sh:59-60 ack loop c=8 and
c=64 only (c=1 was hand-run, bench/out/node-ack-c1-r1.json, e129c77, kernel fc-v180). RESULTS.md:412-415: c=64 p99 12.5 ms even with
synchronous_commit off → CPU-bound on 4 vCPU. This VM: kernel 6.18.44-fc-v185, 4 × "Intel(R) Xeon(R) Processor @ 2.80GHz" (model hidden),
MemTotal 16 477 352 kB, /dev/vda virtio-blk ext4 (discard, write_cache "write back"), /dev/shm tmpfs. Native PG 16 (NOTES "Bench").
