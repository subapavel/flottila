## The fault (a wrong expectation, the same as FIX-213's)

`platform/runtime/src/test/java/io/rail8/runtime/journal/ReplicaStartTest.java`, the test
`aStartCountsTheReplicasAndChecksEachPartAgainstItsHeader`: at :145 it compares `a.bytes()` with the
files on disk right after `holder(JournalFiles.real(), …)`. `Journal` counts the 49-byte header of
the pre-opened next segment from the pre-open's start, before its file exists, so the comparison
races with the pre-open. The file reads and the open call before that line usually hide it; it has
not been seen failing. FIX-213 removed the same race from the sibling test with the `PreopenSeen`
wrapper of `JournalFiles` that is now in the class.
