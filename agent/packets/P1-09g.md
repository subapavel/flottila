## Acceptance
- `flottila-api` `Component`: `default Optional<InetSocketAddress> listensOn(EndpointConfig cfg) { return Optional.empty(); }`,
  `@since 0.1`, javadoc: the local host and port a consumer of cfg binds if it accepts connections; empty if it polls,
  subscribes or connects out; answered from cfg alone (already schema-valid), unresolved (`createUnresolved`), no bind, no DNS;
  port 0 (ephemeral) is never compared; called at deploy and restore on a virtual thread; a throw becomes a problem line.
- http: `listensOn` = `createUnresolved(host option or "127.0.0.1", port option, else URI port, else 0)` from ONE private
  helper the `HttpConsumer` constructor (HttpComponent.java:169-170) also uses. Confirm by javap (Vert.x 5.1 jar) how servers
  are shared; record the observation in the handback. `InetAddress.ofLiteral` — confirm by javap on the JDK before use.
- runtime.deploy `Listeners` (package-private, static) `overlap(a, b)`: same port, port ≠ 0, and hosts equal after normalising
  (strip [ ], IP literal parsed without DNS, else lower-cased name) or either host is a wildcard (`isAnyLocalAddress`, or blank).
- `Deployments.check(...)` refuses, one INVALID line each, before anything is built or stopped, an `in` endpoint that feeds a
  flow (config valid, environment overlay applied) whose `listensOn` overlaps: (a) another of the same new version (once per
  pair, reported on the later flow id); (b) the node's admin listener (`config.admin()` host:port); (c) a running flow
  (`Flow::runs`) of another RUNNING package. Excluded: the deploying package's current version; FAILED flows and packages.
  The taken set is read under the deploy lock.
- Line [A — own flows by local id, other packages qualified, as existing lines]:
  `flow 'orders' (endpoint 'orders-in') listens on 0.0.0.0:8080, which overlaps 127.0.0.1:8080 of flow 'billing/invoices'
  (endpoint 'invoices-in'): one listener per port on a node (D-072)`; admin: `… of the node's admin API
  (FLOTTILA_ADMIN_HOST/PORT) …`. Host shown as configured, IPv6 in brackets. A throwing `listensOn` is one line naming the
  endpoint and scheme.
- Restore runs the same check (install → check): the later package of a clashing pair is FAILED with that line; /health DOWN.
- Docs are the architect's (done in this task's commit): ARCHITECTURE §7 snippet + sentence + changelog row; D-072.
