A modern open-source alternative to legacy integration middleware: Java 25 virtual threads, Vert.x 5, fast by design, every message traceable end to end. Apache 2.0.

  • Repository on GitHub
  • Quick start

What that means

Every message in flight runs on its own virtual thread, and a large message body is streamed, not held whole in memory. “Fast by design” describes how Rail8 is built, not a measured number.

Every message and every step is recorded and searchable, with its payload up to a recording limit, so each message can be followed from the moment it arrives to the moment it leaves.
