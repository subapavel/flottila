## The fault

`bench/src/test/java/dev/rail8/bench/NodeBenchMainWarmupIT.java`,
`aSyncWindowsJournalRateHoldsTheRecordingThatLandsAfterTheReplies` (line 109-112):
`double delta = journalBytesPerSecond * elapsedMs / 1000.0` is compared with the whole number
`recorded` by `delta >= recorded`. The report's rate is a whole byte count divided by the elapsed
seconds (`NodeBenchMain.java:859`, `(after.journalBytes() - before.journalBytes()) / seconds`), and
`elapsedMs` is `elapsedNanos / 1_000_000.0` (:672); multiplying back gives the count only up to
floating-point rounding. When the journal grew by exactly the recorded bytes, the product came out
half an ulp short and the test failed for a rounding, not for a missing record.
