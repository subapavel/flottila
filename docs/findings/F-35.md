# F-35 — Journal copies need a node-to-node link

Date: 2026-11-12 · Task: CORE-5a · ARCHITECTURE section: §4 "Event bus", §4 "Body journal", §7 (version 3.17)

- **Assumption in the document:** nodes share state only through Postgres and Valkey (§4 Event bus). All contact with the outside
  world goes through the Component SPI, and nothing else opens a socket (CLAUDE.md design rules, §7). Bytes exist in the system once.
- **How it fails in practice:** CORE-REWORK §3 and Q-5 want each body on a second node before the ACK, and a body read on any node.
  No store may carry the bytes: Postgres and S3 were rejected for the body path (O-4, O-5), Valkey loses state, and Kafka is out of
  the core (O-1). The Component SPI carries Envelopes to partners. Its mock would be refused when deployed, and there is nothing to
  mock per environment. So the copies need a direct node-to-node link that none of the rules above allows.
- **Severity:** major (a new channel between nodes; the documented intent, one durable copy per configured count, stays).
- **Change made:**
  - **The link:** an internal runtime package `io.flottila.runtime.journal.peer` runs a TCP link between nodes (Vert.x
    NetServer/NetClient). It carries journal frames only, and every frame is authenticated by an HMAC under a session key derived
    from the environment's master key (D-106).
  - **The Component SPI rule:** it keeps its meaning for contact with partners. The admin listener, the store clients and now the
    peer link are the runtime's own sockets.
  - **Copies:** a copy is byte-identical and is one logical object addressed by (owner, segment). "Bytes exist once" means one
    logical object, kept on `copies` nodes.
  - **ArchUnit:** a rule confines Vert.x `io.vertx.core.net.Net*` to `journal.peer` (this finding is its finding-first; the JDK's
    `java.net` and NIO sockets follow in FIX-180), so "nothing else opens a socket" stays enforced.
  - **What the link shows:** bodies travel as the journal's AEAD ciphertext; record metadata (message ids, steps) travels in clear
    under the HMAC. TLS can wrap the link later without a frame change.
- **ARCHITECTURE.md edit:** §4 Event bus and Body journal sentences, the §7 Component SPI sentence, and the changelog row of the version that ships CORE-5a.
- **PROGRESS entry:** CORE-5a marked `Deviation: F-35`.
- **Owner's answer (2026-11-12, D-138):** HMAC under the environment key, TLS later; copies count as one logical object.
