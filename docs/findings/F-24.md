# F-24 — no deployed path binds `MessageContext`: a message has no deadline

Date: 2026-11-03 · Task: P2-09 · ARCHITECTURE section: §4 (version 3.4)

- **Assumption in the document:** §4 "`ScopedValue` carries message id, tenant, trace id and deadline through every step".
- **How it fails in practice:** `MessageContext` is bound only by `Admitted.run`, which only flottila-bench (ScopeBench) calls;
  FlowWorker, the sync/at-most-once ingress paths and Replay never bind it, so a step or stage that asks for the deadline finds
  none. P2-09's "a call that cannot get a permit within the message deadline" therefore has no deadline to use.
- **Severity:** major
- **Evidence:** `grep -rln MessageContext flottila-*/src/main` (2026-11-03, f0ac87d): scope/MessageContext, RequestScope,
  admission/Admitted, record/Trail, bench ScopeBench — no runtime or flow caller of `Admitted.run`.
- **Change made:** none in P2-09: its per-target wait is bounded by its own `maxWait` (D-099). FIX-115 binds the context on every
  deployed path; then the target wait takes the earlier of maxWait and the deadline.
- **ARCHITECTURE.md edit:** none until FIX-115 (the § sentence states the intent).
- **PROGRESS entry:** P2-09a marked `Deviation: F-24`
- **For the owner's review:** whether the deadline belongs to every delivery mode (sync: the http timeout; at-least-once: the lease).
