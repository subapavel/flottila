# F-37 — §12's module layout and names change with the rename to Rail8

Date: 2026-11-15 · Task: BRAND-1 · ARCHITECTURE section: §12 (version 3.22)

- **Assumption in the document:** §12 lists one flat Maven monorepo, `~/flottila/`, with modules
  named `flottila-api`, `flottila-core`, `flottila-runtime`, … in the repository root, and no place
  for the mapping engine, which lived in its own repository.
- **How it fails in practice:** the owner renamed the product (D-145) and asked for the repository
  to be cleaned up after Apache Iggy and for the mapping engine to move in (D-148). A directory
  named after the old product, sorted in the root among `agent/`, `ci/` and `docs/`, is what the
  owner asked to remove; and the mapping engine has modules called `api` and `runtime` of its own,
  so a flat root cannot hold both without a prefix.
- **Severity:** minor — names and directories change; no mechanism, no dependency rule and no
  ArchUnit rule changes. The rules key on Java packages; only the package root they name moves
  from `io.flottila` to `io.rail8`.
- **Evidence:** D-149 (the layout and coordinates, with the designer's draft and the opponent's
  hand-back in `agent/work/BRAND-2-*.md`); the whole-reactor run after each of the three rename
  commits against the BASE-1 red set, recorded in `docs/PROGRESS.md`.
- **Change made:** the platform's modules sit under one area directory, `platform/`, without the
  product prefix; the parent pom is `platform/pom.xml` and the root pom a thin aggregator; the
  benchmark module joins its scripts and `RESULTS.md` in `bench/`; the mapping engine is the area
  `mapping/` with its own parent pom (BRAND-3, D-150). Artifact ids keep a product prefix
  (`rail8-api`), because a jar's file name must stay unique beside `rail8-mapping-api`. The
  dependency direction `api <- core <- runtime` and every other rule of §12 stand as written.
- **ARCHITECTURE.md edit:** changelog 3.23 — §12 rewritten to the new layout and names, with a row
  for `mapping/`.
- **PROGRESS entry:** BRAND-1 marked `Deviation: F-37`.
- **For the owner's review:** the area name `platform` (rejected: `core` — the module keeps that
  name; `engine` — clashes with `mapping/engine`; `server` — the CLI, the testkit and the schemas
  are not a server), and the coordinates `io.rail8` while no `rail8.io` domain is registered
  (ISSUE-7).
